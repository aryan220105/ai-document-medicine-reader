# Dosage Label Terminology

This file explains common printed phrases. It does not recommend a dose.

## Common printed phrases

- As directed by physician
- As directed by the doctor
- Take one tablet twice daily
- Take one capsule once daily
- For external use only
- Shake well before use
- Not for injection
- Keep out of reach of children

## Units

Preserve printed units exactly:

- mg
- mcg
- g
- ml
- IU
- %

## How to explain dosage text

Repeat the printed instruction in simple language.
If the instruction is incomplete, say that only the printed fragment is available.
Do not calculate a new dose from body weight or age.
Do not convert a printed adult dose into a child dose.
